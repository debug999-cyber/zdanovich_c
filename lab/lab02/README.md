## Ответы на вопросы

### Как объявить структуру?
struct student { char name[100]; int age; };

### Что такое вложенные структуры?
Когда внутри одной структуры есть другая структура.

### Как передать структуру в функцию?
По значению - func(struct student s)
По указателю - func(struct student *s)

### Можно ли создавать массивы структур?
Да. struct student students[5];

### Как обратиться к элементу массива структур?
students[0].name - через точку
students[0]->name - через указатель

### Можно ли использовать enum внутри структуры?
Да. struct student { enum course course; };

### Можно ли сравнивать структуры оператором ==?
Нет. Нужно сравнивать каждое поле отдельно.
